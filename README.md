# 🌦️ React Weather App

A modern and responsive weather application built with **React**, **Vite**, and **WeatherAPI**. It provides real-time weather information for any city with a clean glassmorphism UI and mobile-friendly design.

---

## 🚀 Live Demo

🔗 https://react-weather-app-topaz-eight.vercel.app

---

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- ☁️ Current weather condition with icons
- 💧 Humidity
- 🌬️ Wind Speed
- 🌡️ Feels Like Temperature
- 👀 Visibility
- 🎨 Modern Glassmorphism UI
- 📱 Fully Responsive Design
- ⚡ Fast performance using Vite

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/crafted-by-tarun/react-weather-app.git
```

Go to the project folder

```bash
cd react-weather-app
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

## 🔑 API

This project uses **WeatherAPI** for fetching real-time weather data.

Create a `.env` file in the root directory and add:

```env
VITE_API_KEY=YOUR_API_KEY
```

Get your free API key from:

https://www.weatherapi.com/
